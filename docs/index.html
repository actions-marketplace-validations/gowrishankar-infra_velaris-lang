The language where you can trust code you didn't write.

A Velaris signature tells you everything: the types, the effects it may perform, whether it can fail, and promises that are proven by the Z3 theorem prover before the program runs — in genuine IEEE-754 for floats. Pure numeric functions compile to native code via LLVM.

Effects are visible
A function without uses net can never touch the network. Hidden behavior does not compile.
Promises are proven
ensures result >= 0 is checked by Z3 for every possible input, with exact counterexamples when broken.
Failure is unignorable
or fail in the signature; forgetting the error path is a compile error — builtins included.
Fast where it's safe
Pure Int/Float/Bool functions run as machine code, verified identical to the interpreter.

Sixty seconds of Velaris

fn discount(price: Int) -> Int
    requires price >= 0
    ensures result >= 0        // PROVEN before running
{
    return price - 10           // error[E700]: price = 5 gives -5
}
